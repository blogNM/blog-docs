# Creat_ 설계 문서

블로그 플랫폼 **Creat_**의 요구사항과 설계 문서를 모아 둔 저장소입니다.

- 사이트: https://creat.java21.net
- 소스코드: https://github.com/blogNM/blogproject

회원이 블로그를 만들고 다른 회원과 함께 운영하는 티스토리형 블로그 플랫폼입니다. 이 저장소에는 코드는 없고, 무엇을 왜 그렇게 만들었는지 적은 문서만 있습니다.

## 어떻게 만들었나

1. **요구사항은 팀이 함께 분석했습니다.** 팀원들이 모여 요구사항분석서 두 편을 썼습니다 (2026-10-02).
   - 1편 기본 요구사항: [docs/01-requirements](docs/01-requirements/요구사항분석서_1_기본요구사항.pdf)
   - 2편 세부 정책·결정 기록(D-01~D-81): [docs/02-policies](docs/02-policies/요구사항분석서_2_세부정책_결정기록.pdf)
2. **블로그는 팀원마다 따로 만들었습니다.** 같은 분석을 바탕으로 팀원 한 명 한 명이 자기 블로그를 직접 구현했습니다. 그래서 팀원마다 구현한 모양과, 만들면서 정한 내용이 서로 다를 수 있고 원래 문서와도 다를 수 있습니다.
3. **이 저장소의 문서는 그중 하나인 Creat_를 따릅니다.** PDF 두 편은 팀이 함께 쓴 원본 그대로 두었고, 그 밖의 문서(spec, 결정 기록 D-82부터, ERD, 안내서, 릴리스 노트, 변경 기록)는 Creat_를 만들면서 쓰고 고친 것입니다.

## 어디부터 읽나

1. [헌법](.specify/memory/constitution.md): 모든 기능에 걸리는 규칙부터 봅니다.
2. [기능 명세 목록](specs/README.md): 기능 5개가 어떻게 나뉘었는지, 아직 확인이 필요한 항목이 무엇인지 봅니다.
3. 기능별 spec: [001 회원](specs/001-member-account/spec.md) → [002 블로그](specs/002-blog-management/spec.md) → [004 게시판](specs/004-board/spec.md) → [003 소셜·알림](specs/003-social-notification/spec.md) → [005 관리자](specs/005-admin-moderation/spec.md) (만든 순서). 요구사항 ID 접두어로 찾습니다: USR→001, BLG→002, SOC→003, BRD→004, ADM→005.
4. [결정 기록](docs/03-decisions/README.md): spec의 Clarifications에 적힌 D-번호를 따라가면 왜 그렇게 정했는지 나옵니다. D-01~D-81은 2편 PDF 8장, D-82부터는 `docs/03-decisions/`에 있습니다.

## 구현하며 반영한 부분

Creat_를 만들면서 더하거나 정한 것들입니다. 자세한 내용은 결정 기록과 [CHANGELOG](CHANGELOG.md), [릴리스 노트](docs/releases/)에 있습니다.

### 계정·로그인

- [D-99](docs/03-decisions/D-99-가입-이메일-중복-확인.md) 가입 화면에 이메일 [중복 확인] 버튼. 이미 가입된 이메일이면 화면에서 바로 알려 줍니다 (IP별 1분 20번까지)
- [D-103](docs/03-decisions/D-103-구글-로그인.md) 구글 로그인. Spring Security OAuth2 Client로 받고, 로그인 뒤에는 이메일 로그인과 같은 JWT 쿠키를 씁니다
- [D-107](docs/03-decisions/D-107-네이버-로그인.md) 네이버 로그인. 구글과 같은 흐름·테이블에 등록만 더했습니다
- [D-108](docs/03-decisions/D-108-카카오-로그인.md) 카카오 로그인. 인증된 이메일만 받고, 구글·카카오는 매번 계정 고르기 화면을 띄웁니다

### 블로그

- [D-89](docs/03-decisions/D-89-블로그-테마-틀.md) 블로그마다 테마 틀 7가지 중 하나를 고르고 강조 색·글꼴·머리 사진·문구로 꾸밉니다
- [D-101](docs/03-decisions/D-101-만들기-테마와-블로그-골라-글쓰기.md) 블로그를 만들 때부터 테마를 고르고, 메인의 [글 작성하기]에서 내 블로그를 골라 글을 씁니다
- [D-87](docs/03-decisions/D-87-제재-횟수.md) 경고·정지 3회는 블로그별로 세고, 1년 지난 것은 뺍니다
- [D-96](docs/03-decisions/D-96-블로그-공유-미리보기.md) 블로그 주소를 공유하면 미리보기에 블로그 이름·소개·대표 이미지가 보입니다

### 글·에디터

- [D-88](docs/03-decisions/D-88-태그-금칙어-제외.md) 태그 금칙어는 만들지 않습니다
- [D-92](docs/03-decisions/D-92-링크-미리보기-카드.md) 글 속 링크를 썸네일·제목·설명 카드로 보여 줍니다. 서버가 저장할 때 한 번만 받아 옵니다
- [D-93](docs/03-decisions/D-93-글자-색.md) 글자 색 7가지. 본문에는 정해 둔 색 class만 남깁니다
- [D-106](docs/03-decisions/D-106-보이는-그대로-편집기.md) 보이는 그대로 쓰는 편집기와 옆 창의 [HTML 보기]. 저장 형식은 그대로 마크다운입니다
- [D-110](docs/03-decisions/D-110-체크박스-목록과-글자-크기.md) 체크박스 목록을 더하고, "아주 크게"가 굵게까지 걸던 것을 뺐습니다

### 소셜·알림

- [D-85](docs/03-decisions/D-85-신고-접수처.md) 신고 접수처: 블로그 안 멤버는 블로그장, 블로그장과 메인 프로필 신고는 메인 관리자
- [D-91](docs/03-decisions/D-91-내-활동-화면.md) [내 활동] 화면(쓴 글·좋아요 한 글·팔로잉·구독). 목록마다 공개 여부를 고릅니다

### 관리자

- [D-84](docs/03-decisions/D-84-관리자-계정-분리.md) 메인 관리자는 회원과 따로 있는 계정이고 블로그 활동을 하지 않습니다

- [D-98](docs/03-decisions/D-98-공지-카테고리.md) 공지 카테고리: 일반·업데이트·수정·점검
- [D-102](docs/03-decisions/D-102-관리자-공지-편집-도구.md) 관리자 공지 쓰기에 서식 도구(크기·색·형광펜·사진·미리보기)
